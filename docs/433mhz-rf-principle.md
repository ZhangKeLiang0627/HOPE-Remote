# 433MHz 射频（RF）遥控原理

> 面向本项目（HOPE-Remote，STM32F401RE + 远-T2L 发射 / 远-R1 接收）的原理图解。
> 理解它，才能读懂 xx101 学习、fs101 回放、dbg/raw/adcmon 诊断背后到底发生了什么。

---

## 1. 一句话总结

**433MHz 遥控 = 用"载波有没有"来传信息。** 发一个遥控码，本质就是：在正确的时间点把 433.92MHz 的载波**开一关、开一关**，接收端把这些开关时段还原成一个电平信号，最后被 MCU 按"每个电平段持续多久"记录下来。

---

## 2. 物理层：433MHz ISM 频段

- 433MHz 属于 **ISM 免执照频段**（433.05 - 434.79 MHz，常用中心频率 433.92 MHz）。
- 中国允许免执照使用，但功率受限（通常 ≤ 10mW EIRP），这也是遥控器通信距离一般在几十米内的原因。
- 波长 ≈ 0.69m，天线可以做得非常小（四分之一波长 ≈ 17cm，用螺旋/鞭状做短）。

```
无线电波示意（载波开 = 一个正弦波串）：

  发射（DATA=高）:   ~~~~~~~~  ~~~~~~~~  ~~~~~~~~   ← 载波突发
  发射（DATA=低）:   (静默)
```

---

## 3. 调制方式：OOK / ASK

OOK（On-Off Keying，开关键控）是 ASK（幅移键控）的一种特例：

- **DATA = 高** → 振荡器开，辐射 433.92MHz 载波
- **DATA = 低** → 振荡器关，完全不辐射

```
  基带 DATA:       ┌────┐   ┌──────┐   ┌──┐
       高  ────────┘    └───┘      └───┘  └────────
       低  ──────────────────────────────────────

  RF 输出:         ┌────┐   ┌──────┐   ┌──┐
   载波ON ─────────┘    └───┘      └───┘  └────────
        ├──────┤ ├────────┤ ├────┤
       载波存在  载波不存在  载波存在        ← 这就是"码"
```

所以射频遥控码的**信息全在时间轴上**：载波段多长、间隔段多长、按什么顺序出现。

---

## 4. 发射端：远-T2L

发射模块内部基本就是"一个受 DATA 控制的 433.92MHz 振荡器 + 功率放大"：

```
        ┌──────────────────────────────────────┐
 DATA ─▶│  基带整形 → 振荡器开关(S) → 功放(PA)  │──▶ 天线
(基带电平)│  频率由 SAW 谐振器稳频 433.92MHz      │
        └──────────────────────────────────────┘

  DATA 高 → 振荡器 ON  → 天线辐射 433.92MHz 载波
  DATA 低 → 振荡器 OFF → 静默
```

在本项目里，回放时 `RfTransmitter::play()` 直接驱动 PA2 输出基带电平：
`段为 mark(+) → PA2 置高 → T2L 发载波`。

---

## 5. 接收端：远-R1

接收端是**超外差（superheterodyne）**或**超再生**结构。共同点是：天线收到载波突发后，经过放大、变频、检波、整形，最终在 DATA 引脚输出一个**解调后的数字电平**——相当于"载波存在/不存在的指示"。

```
          天线
           │
           ▼
   ┌──────────┐   ┌──────┐   ┌─────────┐   ┌──────┐   ┌─────────┐   ┌────────┐
   │  LNA      │──▶│ 混频   │──▶│ IF 滤波/ │──▶│ 检波   │──▶│ 比较器    │──▶│ DATA    │
   │ 低噪声放大 │   │ ×本振  │   │ 中频放大  │   │ 解调OOK│   │ 整形判门限 │   │ 输出    │
   └──────────┘   └──────┘   └─────────┘   └──────┘   └─────────┘   └────────┘
                      │                                            (TTL/CMOS 电平)
                      │ 本振(SAW 稳频，433.92MHz ± IF)
```

关键点：

- **DATA 输出的就是"解调后的基带包络"**，时序和发射端 DATA 一致（或反相，见 §10）。
- 没有遥控信号时，接收机也会输出**空闲电平**（本项目实测远-R1 空闲 ≈ 0V）。
- 超外差接收机有开机建立时间，首个 bit 可能不稳，所以遥控帧都会**重复发好几遍**。

---

## 6. 从发射到 MCU 的完整链路（本项目）

```
  远-T2L                    空间 433.92MHz            远-R1
 ┌────────────┐  载波ON/OFF   ┌────────────┐  解调出   ┌────────┐
 │ DATA→振荡器 │ ───────────▶ │ 天线→接收机 │ ────────▶│ DATA   │
 └────────────┘               └────────────┘           └───┬────┘
                                                            │ 5V 逻辑电平
                                              ┌─────────────┴─────────────┐
                                              │ 分压：5V→3.3V(模拟引脚不耐5V) │
                                              │   DATA ─[10k]─┬─[20k]─GND    │
                                              └─────────────┬─┘              │
                                                            │ PA4 (ADC1_IN4)
                                                            ▼
                                              MCU 连续采样(3周期) → 相邻|Δ|>100 判边沿
                                              → TIM2(1μs) 计每段时长 → 段数组(mark/space)
```

**为什么 ADC 采集而不是 GPIO 读电平？**
因为要精确测每一段**持续了多久**（μs 级）。用 ADC 连续采样 + 边沿判定 + 定时器计时，能把电平变化转化为带符号时长数组，这就是"原始波形捕获（raw）"。

> ⚠️ 本项目实测的一个坑：PA4 是高阻源（10k 串联），如果 ADC 采样时间拉太长（84 周期 ≈ 4μs），采样保持电路对源强拉电流会诱发振荡、在空闲线上采出假边沿。所以 RF 走**连续模式 + 3 周期采样**。

---

## 7. 数字时序：把信号想成"段"

MCU 不关心位流，只关心电平段：

```
采样到的电平:   ┌────┐  ┌──────┐  ┌──┐
       高  ─────┘    └──┘      └──┘  └────
       低  ─────────────────────────────

存成带符号时长数组（μs，正=mark/载波，负=space/无载波）:
        +400    -1200    +400   ...
```

这其实是**协议无关**的表示——不管编码是 EV1527、PT2262 还是随便什么自定义协议，都能这样存、这样放。这也是本项目选择 raw 学习/回放的根本原因。

---

## 8. EV1527 协议（远-T2L 几乎确定是这一族）

EV1527 系列（含 HS1527/RT1527 等）是 433MHz 固定码遥控最常用的编码方案，串口里能看到 `399/1203/1196/1191/405` 这样的时长就是在采集它。

**时基 T ≈ 400μs**，全部码都由 1T 和 3T 组成：

```
  bit0  = 1T 载波 + 3T 无载波   →  400μs ON  + 1200μs OFF
  bit1  = 3T 载波 + 1T 无载波   →  1200μs ON + 400μs  OFF
  sync  = 4T 载波 + 124T 无载波  →  1600μs ON + ≈50ms OFF
```

一帧的波形：

```
        sync           bit0          bit1          bit1
        ┌────┐        ┌─────┐       ┌──────────┐  ┌──────────┐
载波ON  ┘    └────────┘     └───────┘          └──┘          └──────
       ├──1600─┤  ├─400─1200─┤  ├─1200──400──┤  ├─1200──400──┤
        4T+124T      1T+3T         3T+1T          3T+1T
```

完整帧规则：

```
  sync + 20bit(地址/数据，低位在前)  →  一帧
  每按一次，完整帧重复 3-4 遍，帧间间隔 ≈ sync 的长空闲(≈50ms)
```

- 按我们的实测：`-399,+1200,-403,+1196,-1191,+405`（取反后）正好是 `bit0、bit0、bit1`，T≈400μs，实锤远-T2L 是 EV1527 族。
- 因为码率低（T=400μs，一帧才 ≈8ms），接收端 ADC 采样完全跟得上，raw 学习/回放很稳。

## 9. 与红外（NEC）对比

| 维度 | 红外 IR (NEC) | 射频 RF (EV1527) |
|---|---|---|
| 载波频率 | 38kHz | 433.92MHz |
| 调制 | OOK（38kHz 载波开/关） | OOK（433.92MHz 载波开/关） |
| 介质 | 光，需对准、有遮挡就断 | 无线电波，可穿墙、无需对准 |
| 基本时基 | 562μs（NEC） | 400μs |
| 引导码 | 9ms + 4.5ms | sync = 1.6ms + ≈50ms |
| 数据位 | 32bit（地址+命令） | 20bit（地址+按键） |
| 接收头 | HS0038：空闲=高、载波=低 | 远-R1：空闲=低、载波=高 |
| 重复帧 | 单发 | 连续 3-4 帧 |

**共同点**：都是 OOK，MCU 侧都是"按电平段时长学习/回放"，所以本项目 IR/RF 共用同一套 `Receiver` 状态机。

## 10. 模块输出极性：HS0038 vs 远-R1（本项目踩的坑）

红外接收头 HS0038 把载波解调为**低**（空闲为高）；而远-R1 正好相反，把载波解调为**高**（空闲为低）。固件存储时必须把"载波段"记为 mark(+)，否则信号会整体反相、回放发不出去。

```
  HS0038（红外）:                    远-R1（射频）:
   载波ON → 输出 低                   载波ON → 输出 高
   空闲   → 输出 高                   空闲   → 输出 低

  DATA: ┌───┐   ┌──┐               DATA:     ┌───┐   ┌──┐
  高 ───┘   └───┘  └───             高 ───────┘   └───┘  └───
  低 ───┐      ┌───┐                 低 ─┐      ┌───┐
       载波  空闲  载波                 载波  空闲  载波
  （空闲=高）                         （空闲=低）
```

本项目处理方式：录制开始时先测空闲基准，得到 `idleLevel_`（高或低），之后：

- **空闲结束判定**：电平回到 `idleLevel_` 并保持 100ms → 信号结束
- **存储极性**：`当前电平 != idleLevel_` 记 mark(+)，否则记 space(-)

这样两种极性的接收头都能正确工作（HS0038 路径行为与原来完全一致）。

---

## 11. 为什么 raw 学习/回放是"协议无关"的

遥控的本质是**一串带时间的电平段**，而不是"比特流"。本项目只做三件事：

1. **学**：测出每段电平 + 时长 → 存数组
2. **存**：段数组进 Flash 槽
3. **放**：按段数组驱动发射端（mark 段 → PA2 高 → 载波 ON）

它**不解析 EV1527 的位含义**，所以：
- 任何 EV1527 变体、PT2262、自编码遥控都能学
- 不需要关心遥控器芯片版本、滚动码/固定码（注意：真滚动码遥控每帧码变，学了也放不出来，本方案面向固定码）
- 唯一前提：遥控是 OOK 调制、固定码（绝大多少 433 遥控都是）

## 12. 诊断命令怎么看（对照本文）

| 现象 | 含义 |
|---|---|
| `adcmon4` 空闲恒为 ≈87 | 远-R1 空闲输出 ≈ 0V（空闲低），**正常**，不是坏 |
| `dbg4` 按遥控时 `min=0 max=4095 edges≈4800` | 载波开/关全幅摆动，接收链路健康 |
| `xx101` 采到 `399,1203,1196,1191,405` 附近时长 | 就是 EV1527 的 1T/3T 码型，抓对了 |
| `xx101` 采到 510 段且不停 | 假边沿（长采样诱发），应走连续+3周期模式 |
| `xx101` 一直等到 15s 超时 | 空闲电平判错了极性，空闲结束没触发 |
