# RF 串口模块方案：调试与测试手册

> 本文档记录 HOPE-Remote RF（433MHz 串口模块方案）的调试命令、回放时序结论与发射参数试验指南。
> 面向调试与二次开发，日常使用请参考根目录 README。

## 1. 回放时序结论（排查全过程总结）

**正确时序 = RCSwitch protocol 1 标准**（与 433_test_arduino 的 ESP433RF/RCSwitch 一致）：

```
[24bit 数据 MSB first][sync: 1×pulse 载波 + 31×pulse 空闲]
bit0 = 1p 载波 + 3p 空闲；bit1 = 3p 载波 + 1p 空闲
pulse = 320μs，回放用原码（code24）
```

**发射参数（三盏灯实测通杀）**：`8 帧 × 1 簇 × 帧间隔 5ms × 簇间隔 300ms`

### 排查教训（重要）

| 现象 | 结论 |
|---|---|
| 模块回环 `[TARGET MATCH]` 但目标灯不认 | ⚠️ **串口模块与目标设备解码偏好不同**：模块只认长载波 sync（31p+1p），目标设备（灯）认标准 1p+31p——**模块回环不能验证回放正确性**，以目标设备实测为准 |
| 模块对标准 1p+31p 收不到帧 | 正常（模块只认长载波 sync），不代表发射失败 |
| 帧间隔 10ms 灯"时好时坏" | 相邻帧"粘连"，接收端帧结束判定被打断；但 5ms 紧凑间隔实测反而更有效（接收端保持同步） |
| 单簇无反应、连点有反应 | 目标设备低功耗轮询，第一簇唤醒、后续簇生效；但三灯实测 1 簇 + 8 帧已足够 |

## 2. 调试命令

| 命令 | 说明 |
|---|---|
| `rfmon` | 监听 USART2 码流（串口模块原始输出），`x` 退出 |
| `rfloop` | 空气回环：PA5 发 0x55C311（标准时序 8 帧）→ 模块回收比对。模块 `no rx` 属正常 |
| `rfraw` | PA4 采样解调波形（需模块 DATA 输出接 PA4），用于抓取真实遥控器波形 |
| `rfscanNNN` | 发射槽 NNN 码的 15 种编码变体（sync 比例 × 位序 × pulse），目标设备实测定位 |
| `rfscan2NNN` | sync-前置比例精扫 21 种（模块回收判 MATCH）。⚠️ 模块对连续发射免疫差，结果不可靠 |
| `evtest` | EV1527 编解码往返自测（软件层，不依赖硬件） |
| `dbg` | IR ADC 采样 1s 统计（PA0/HS0038） |
| `raw` | 捕获 3000ms IR 原始波形打印（PA0） |

## 3. 发射参数试验指南

`fsNNN [帧数 簇数 帧间隔ms 簇间隔ms]`（默认 `8 1 5 300`）：

```
fs103 1 1         ← 单帧单簇（最小粒度）
fs103 5 1         ← 5 帧单簇
fs103 8 1 5 300   ← 显式指定（三灯通杀参数）
fs103 15 1 5 300  ← 15 帧（长按类）
```

- 帧数 1~30、簇数 1~10、帧间隔 0~1000ms、簇间隔 0~2000ms
- 不同目标设备对帧数/间隔敏感度差异大（实测三盏灯各有偏好），参数化接口用于逐台调优

## 4. 硬件备忘

- 串口模块：灵-R1A-M5（串口版），TX → PA3（USART2_RX @9600）
- 发射模块：远-T2L，DATA ← PA5（3.3V 直驱基带，mark=高=载波 ON），**必须接 17cm 天线**
- 学习去抖：连续 2 帧相同码即确认保存（按下瞬间完成）
